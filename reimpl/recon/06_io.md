# Recon 06 — IO / VFS / Save / Audio / Net / CopyProtect / App Lifecycle

Binary: `gilde.exe` ("Die Gilde" / "The Guild Gold"), 32-bit x86, imagebase 0x400000.
Engine internally named "VIBE"/"X-Engine" (paths reference `x:\engine\gfx\...`). Functions named `VIBE_<Module>_<Action>`.
Scope of this document: file/asset IO, VFS, savegames, audio (Miles), networking transport, copy-protection, top-level app/game lifecycle.

## 1. App Lifecycle — the program spine

### WinMain: `VIBE_GameLogic_MainEntryAndShutdown` @ **0x534bbc** (`__stdcall(hInstance, hPrev, lpCmdLine, nShow)`)

Step by step:

1. **Module path & INI discovery.** `GetModuleFileNameA(hInstance, g_exePath[0x122F638])`. Copies to `g_exeDir[0x122F73C]`, truncates last `\` → exe directory. Builds `<exeDir>\gilde.INI` into `g_exePath` (config file path reused as the `lpFileName` for every `GetPrivateProfile*`).
2. **Read `gilde.INI`** (all via `GetPrivateProfileStringA/IntA`):
   - `[Network] Server` → server DLL path, default `Server\Server.dll` (→ `g_serverDllPath[0x122F284]`; dir part → `0x122F388`).
   - `[Gfx] TextureDivider` → `0x63C790`.
   - `[Sound] msx`→`g_cfgMusic[0x63C8F8]`, `ambient`→`0x63C8FC`, `sfx`→`g_cfgSfx[0x63C900]`, `weather`(def 1)→`0x63C904`.
   - `[General] Bildmodus` ("FULLSCREEN"/else) → display mode `v113` = 3 (fullscreen) or 1 (windowed).
   - `[General] GfxPath` (def `\project\gfx\` → `g_gfxPath[0x63C908]`), `GamePath` (def `\project\game\` → `g_gamePath[0x63CA0C]`), `MoviePath` (def `\project\movie\` → `0x63CB10`).
   - `[General] Language` (def `german` → `0x62EAE4`), then `VIBE_Locale_CopyLanguageString`.
   - `[General] show_intro` → `g_showIntro[0x63C8F0]`; `[Gfx] cur_res` → `g_curRes[0x63D724]`; resolution tables `0x63D70C`/`0x63D710` → `g_resW[0x63D728]`,`g_resH[0x63D72C]`.
   - `[General] Stadt` (def `Augsburg` → `g_cityName[0x122EE50]`), `[Network] Host` (def `128.0.0.1` → `g_netHost[0x122EE90]`), `[Network] Port` (def 7531 → `g_netPort[0x122F490]`).
3. **Command-line parse.** `loc_5CB930` is a `getopt`-like scanner over `lpCmdLine`. Parses quoted tokens: `STADT="..."`, `BERUF="..."` (→ `g_berufName[0x63C7DC]`), `IP="..."` (sets network-game flag `v16=1`), `PORT="..."` (→ `VIBE_Util_ParseInt`→`g_netPort`). Other switches set windowed/fullscreen and `g_cfgFlag[0x63C7B4]`.
4. **Single-instance guard.** `VIBE_App_CreateSingleInstanceMutex` (@0x527d48, `CreateMutex`); if already running → `VIBE_Crt_DoExit`.
5. **Disable screensaver.** `SystemParametersInfoA(SPI_GETSCREENSAVEACTIVE=0x10)` saved in `0x63CC64`; if active, `SPI_SETSCREENSAVEACTIVE(0x11)` off.
6. **Window creation** — `VIBE_Window_CreateMainWindow(hInstance, mode)` @ **0x52895c**. On failure → full shutdown path.
7. **Subsystem init** — `VIBE_App_InitSubsystemsAndMovieDll` @ **0x527de0**. On fail → shutdown.
8. **Intro movie** — if `show_intro`, `VIBE_Movie_PlayIntroSequence` @ 0x5347d4.
9. **Display/DDraw/DInput init** — `VIBE_Render_InitDisplayAndPaths` @ **0x527fa4**. On fail → shutdown.
10. **Engine + script commands** — `VIBE_App_InitEngineAndScriptCommands` @ **0x528560**. On fail → shutdown.
11. **Outer loop:** either auto-start a network game (cmdline IP) / quickstart (`g_startFlags[0x63C798]`) building a default character, or run `VIBE_Menu_RunMainMenu` @ 0x529d08. When a session is chosen → `VIBE_GameLogic_InitOrLoadSession` (loops over `dword_63CC34` players). Resolution-change path tears down render and re-inits via `VIBE_Render_InitDisplayAndPaths`.
12. **Shutdown sequence** (repeated verbatim at every exit; this *is* the teardown order):
    `VIBE_Game_ShutdownSubsystems(0x5278cc)` → `VIBE_Widget_ShutdownSystem` → `VIBE_Config_WriteGfxSettings` → `VIBE_GameState_FreeAllResources` → `VIBE_Universe_SwitchActiveSlot(0)` → `VIBE_Table_ResetLightmaps` → `VIBE_Render_ShutdownEngine` → `VIBE_Input_DirectInputShutdown` → `VIBE_TimeBase_StopTimer` → **`VIBE_Vfs_Shutdown`** → `VIBE_MemPool_ShutdownStack` → `VIBE_Memory_ShutdownTracker` → `VIBE_ErrorLog_Shutdown` → (if movie DLL) `mov_Exit`+`FreeLibrary` → `VIBE_Window_DestroyAndUnregisterClass` → (restore screensaver).

### `VIBE_Window_CreateMainWindow` @ 0x52895c
`RegisterClassA` (class name "Die Gilde", icon "gilde", `IDC_ARROW`, `BLACK_BRUSH`), title `"Die Gilde - <buildversion>"`. Fullscreen (mode 3) → `WS_POPUP|WS_VISIBLE` (style `0x9C000000`), ex `WS_EX_TOPMOST`(8), full-screen pos via `GetSystemMetrics`. Windowed → style `0x6000000`. Stores HWND in `g_hwnd[0x63CC18]`. `ShowWindow(SW_SHOW)`, `UpdateWindow`, `SetFocus`. WndProc filled at `WndClass.lpfnWndProc` (set elsewhere; recover separately — out of this cluster).

### `VIBE_App_InitSubsystemsAndMovieDll` @ 0x527de0
- `VIBE_ErrorLog_Init(handler=VIBE_Game_ShutdownAllSubsystems, …)`, `VIBE_Memory_InitTracker(32678)`, `VIBE_MemPool_StartupStack(0x80)`.
- If `show_intro`: `LoadLibraryA("moveahead.dll")` (Bink/movie wrapper) and resolve exports: `mov_Init_`,`mov_Exit_`,`mov_Play_`,`mov_Stop_`,`mov_SetVisible_`,`mov_GetEvent_`,`mov_Prepare_`,`mov_PrepareDD_`,`mov_Dispose_` into `0x63C768..0x63C788`.
- `CreateDirectory("<gfxPath>gamedata\Screenshots")`.
- **`VIBE_Vfs_Init(gfxPath)`** ← mounts the gfx tree as the VFS root.
- `VIBE_TimeBase_StartTimer(0x0E,0)`.

### `VIBE_Render_InitDisplayAndPaths` @ 0x527fa4
`VIBE_Config_ReadGfxAndSoundSettings` → `VIBE_Render_EnumDisplayModes` (probes available resolutions, flags `0x62D599/9A/9B`) → picks `cur_res` → computes window rect via `AdjustWindowRectEx`+`SetWindowPos` → fills a 24-dword device-descriptor (`v27`: width,height,bpp=16, znear/zfar, fov etc.) → **`VIBE_Render_InitEngineDevice`** (DDraw/D3D device) → `VIBE_Universe_CreateDefaultCameras` → `ShowCursor(0)` → **`VIBE_Input_DirectInputInit(hwnd, hInstance, mode)`** (mode 1 fullscreen / 6 windowed) → sets engine asset sub-paths: `textures/`,`animations/`,`objects/`,`groups/`,`scripts/`,`forms\` → `VIBE_Render_ApplyGfxSettings` → loads master GUI archive **`gilde.gfx`** via `VIBE_Gui_LoadGfxFile` → `VIBE_Widget_InitSystem`.

### `VIBE_App_InitEngineAndScriptCommands` @ 0x528560
Loads text engine (`<gamePath>gilde_text.def` via `VIBE_Text_LoadDefinitionFile`), loading screen (`Misc\Loading_main`), connects net stub (`VIBE_Net_ConnectToServer(0,0)` = local), `VIBE_Command_QueueInitAndSync`, loads building/object data (`<gamePath>data\`), computes market prices. **Audio bring-up** (see §4): if sfx enabled → `VIBE_Audio_StartupMilesDriver`, `VIBE_Sound_LibInit(2097100, 48, 2, 44100)`, `VIBE_Sound3d_InitPool(64)`, `VIBE_SoundWave_InitSineTables`, bank path `<gamePath>sfx\`, load `system.sbf`, preload from `<exeDir>\include_sfx.ini`. If music enabled → `VIBE_Sound_InitThread(2,...,44100)`, track prefix `<gamePath>msx\`. Then registers all script command tables, runs an initial fade, applies camera/scroll config.

### Frame loop
Inner per-frame tick is `VIBE_GameLogic_RunFrameLoop` @ **0x4c09a0** (called from session loop, net wait loops, and fade waits). `VIBE_Window_PumpMessages` @ 0x4bea64 is the `PeekMessage/Translate/Dispatch` pump. The lockstep turn loop lives in `VIBE_GameLogic_InitOrLoadSession` (below).

### `VIBE_GameLogic_InitOrLoadSession` @ 0x533a54 — session bootstrap + lockstep turn loop
Mode selected by bitmask **`g_sessionFlags = word_63C740[0x63C740]`**:
`&1`=new game, `&2`=load savegame, `&4`=network, `&8`=AI/meister, `&0x10`=host (load Server.dll), `&0x40`=load network save, `&0x80`=tutorial.
- Network host (`&4 && &0x10`): `LoadLibraryA(Server.dll)`, `GetProcAddress("Init_")`, call it, `Sleep(2500)`, `VIBE_Net_OpenBroadcastSocket(0x3039=12345)`. Then `VIBE_Net_ConnectToServer(host,port)`.
- `VIBE_Command_QueueInitAndSync`; show loading screen; `VIBE_Game_InitWorldAndSounds`.
- New single game: `sprintf("%s/%s.cty", "gamedata/cities", g_cityName)` and **`VIBE_Save_LoadGameFile`** the `.cty` city file; sync scene (`VIBE_Scene_SyncWorldOnEnter/SyncMeisterBuildings/SyncObjectHeights`).
- Load game: `VIBE_Save_LoadGameFile(g_saveName[0x122F530])`.
- Network load: `VIBE_Net_LoadSavedNetworkGame` / `VIBE_Net_StartNetworkGame`.
- **Turn loop**: repeatedly `VIBE_GameTime_Set/Advance` + `VIBE_Command_QueueRequest*` (enqueue lockstep command, get sequence id) then spin `while(!VIBE_Command_GetPacketStatusById(id)) VIBE_Amt_RefreshGuildState()`. Per round: `VIBE_GameTick_BeginRound`, process turn actions or AI (`VIBE_MeisterAi_RequestCmd58/59/115`), sync-range barrier (`MarkSyncRangeStart/End`, `CheckSyncRangeAcked`), autosave (`Gamedata\Saves\Autosave.SAV` via `VIBE_Save_WriteGameFile`), `VIBE_Scene_RunMainFrameLoop`, advance to next day.
- Network rounds wait on `VIBE_Net_RunSyncWaitLoop` @ 0x4beac8 / `VIBE_Net_RunWaitLoopWithStatus` @ 0x4beb80.

## 2. VFS / Asset System

Mounts a **real directory tree** as a virtual FS and transparently routes file opens to: loose files, gzip files, or files inside ZIP archives. There is **no custom pak container** — the "archives" are standard **PKZIP** files with the extensions `.BIN`, `.BIN0`..`.BIN5` (extension table @ **0x44E8F0**, 6-byte stride; `.BIN5`/`.BIN4`/.../`.BIN0`/`.BIN`). The zlib/zip cluster (`VIBE_Zip_*`, `VIBE_Gzip_*`, `VIBE_Inflate_*`) is the decompression backend.

### Init / scan
- `VIBE_Vfs_Init(rootPath)` @ 0x451f98 → `VIBE_Vfs_ScanDirectory` builds the node tree; root handle in **`g_vfsRoot[0x62EB78]`**. `g_vfsCaseSensitive[0x62EB84]`, `g_vfsOpenCount[0x62EB88]`.
- `VIBE_Vfs_ScanDirectory` @ 0x450234: `FindFirstFileA/FindNextFileA` recursion. For each `.BINx` file it recurses *into* the zip as a virtual subtree; for loose files it calls `VIBE_Vfs_AddFileSorted` storing the DOS-packed mtime (`(year-1980)<<25 | month<<21 | day<<16 | hour<<11 | min<<5 | sec>>1`). Directory nodes via `VIBE_Vfs_GetOrCreateSubDir`. Tree node helpers: `AddFileByPath`, `FindFileRecursive`, `ResolvePath`, `BuildFullPath`, `NormalizeDirPath`, `RemovePathEntry`, `FreeNodeTree`.

### Open / read / write — the key API
`VIBE_Vfs_OpenFile(path, mode, root)` @ **0x450bc8** (the engine's `vfs_Tfopen`): parses mode chars (R/W/T/N/B/Z → flags `read/write/text/binary/gzip`), resolves path through tree. Branches:
- **Inside a ZIP**: `VIBE_Zip_OpenArchive(archivePath)`, optional `VIBE_Zip_SetCurrentFilePosition` (cached offset) or iterate `VIBE_Zip_GetCurrentFileInfo`/`GoToNextFile`, then `VIBE_Zip_OpenCurrentFile`. Handle flag `0x14`.
- **Gzip** (Z mode): `VIBE_Gzip_OpenPath`→`VIBE_Gzip_OpenStream`. Flag `0x08`.
- **Loose file**: `VIBE_File_OpenStream` (buffered CRT-like layer, see §file). Flag `0x10` for zip/raw distinction.
- **Write**: removes existing tree entry, adds new, opens via `VIBE_File_OpenStream`/`VIBE_Gzip_OpenPath`.
Handle allocated from pool `g_vfsHandlePool[0x62EB80]` as a **320-byte struct** via `VIBE_MemPool_Alloc(&pool,320,16)`.

**VFS handle layout (320 bytes)** — offsets confirmed by `VIBE_Vfs_ReadStream`/`OpenFile`:
| off | type | meaning |
|----|----|----|
| +0 | char[256] | file name (the requested path, copied in) |
| +256 (0x100) | void* / FILE* | backing stream: raw `VIBE_File` stream, zip handle, gzip handle, **or** in-memory buffer pointer |
| +260 (0x104) | u32 | remaining bytes (memory-stream mode) |
| +264 (0x108) | u32 | bytes consumed / position |
| +268 (0x10C) | void* | inflate dest ptr (during `VIBE_Inflate_Process`) |
| +272 (0x110) | u32 | inflate dest len |
| +316 (0x13C) | u8 | **flag byte**: `0x01`=open/valid, `0x02`=write, `0x04`=gz-in-zip check, `0x08`=gzip, `0x10`=zip/file, `0x20`=memory-stream, `0x40`=?, `0x80`=? |

### `VIBE_Vfs_ReadStream` @ **0x4514ac** (443 xrefs — the universal reader)
Signature `read(dst, elemSize, FILE* h, count)` (returns elems read). Dispatch on flag byte @+316:
- `0x20` memory-stream: bounded `memcpy` from `h+256`, advances `+256/+264`, decrements `+260`. If also `0x08` → runs `VIBE_Inflate_Process(h+256, mode=2)` into `+268/+272` (in-memory zlib inflate).
- `0x10` zip member: `VIBE_Zip_ReadCurrentFile`. If first read and flag `0x04` set, sniffs gzip magic (`dword_62EB70`/`62EB74`) and warns *"vfs: gz-compressed file in zip found!"* (unsupported nested case).
- `0x08` gzip: `VIBE_Gzip_ReadStream`.
- else raw: `VIBE_File_Read`.
Companions: `VIBE_Vfs_WriteStream` @ 0x4517a8, `ReadByte` 0x451698, `ReadLine` 0x4516cc, `Seek` 0x4518f0 (handles gzip/zip/raw), `Tell` 0x451aa4, `CloseStream` 0x451354, `OpenMemoryStream` 0x451b30 (wraps a RAM buffer as a VFS handle — used for received network savegames). Path utils: `VIBE_Path_ConvertSlashToBackslash`/`ConvertBackslashToSlash` (0x44EB90/0x44EB54).

### Known path strings
`\project\gfx\`, `\project\game\`, `\project\movie\`, asset subdirs `textures/ animations/ objects/ groups/ scripts/ forms\`, `gilde.gfx`, `<gamePath>data\`, `<gamePath>sfx\`, `<gamePath>msx\`, `system.sbf`, `include_sfx.ini`, `gamedata/cities/<city>.cty`, `gamedata/cities/standard.scr`, `Gamedata\Saves\Autosave.SAV`, `Gamedata\Screenshots`, `Gamedata\network\<name>.SAV/.SRV`.

## 3. Savegame format (`Save_*`, `WorldIo`, `GameState`)

Container is just a VFS stream (`.cty` city seed, `.SAV` save, `.SRV` server save, `.scr` thumbnail). No whole-file compression — fields are written with `VIBE_Vfs_WriteStream` raw, **field by field**, in a fixed order. Versioned via a 32-bit magic/version `g_saveVersion[0x649D4C]` (range `0x10025`..`0x10045`; loader gates optional fields on version, e.g. `>=0x10022 read 0x6477A8`, `>=0x1003D port`, `>=0x10045 Amt-table`). This makes the format a **straightforward sequential serializer**, ideal for 1:1 reimplementation.

### Writer `VIBE_Save_WriteGameFile` @ 0x5a348c (mode bits in `bl`: `&2`=network/partial)
`VIBE_Vfs_OpenFile(path,"wb")` → `VIBE_Save_WriteScenarioBlock` (header+version+thumbnail) → a fixed list of scalar/global writes (`0x649890`,`0x632244`, the 14-byte game-time `qword_13CE852`, season byte `0x6477A1`, counters `0x64771C/20/24`, `0xB56450[24]`, etc.) → then the table writers in order:
`WriteMapTileTable` → `WritePersonTable` → `WriteBuildingTable` → **`WriteGameStateHeader`** → `WriteBuildingSlotTables` → `VIBE_Amt_SaveAemter` → (`RelinkPersonExtraData`) → if not partial: `Gesetz_SaveState` → `WriteMapTiles` → `WriteGameGlobals` → `Avatar_Save` → `WriteObjectTable` → `WriteAmtTable` → `WriteHistoryAndCarts` → `WriteActionQueues` → `WriteHotkeyTable` → `WriteCityAndPersonTables` → `Mission_SaveSlotTable` → `Hotkey_SaveTable`. Pointers are converted to ids before write and re-linked after (`RelinkPersonObjects/Records`).

### `VIBE_Save_WriteGameStateHeader` @ 0x5a4938 (representative record serializer)
Iterates the building/scene table (`word_12CE910`, stride **268**, 768 slots, 205824 bytes total). For each live slot (`!= -1`) it writes ~70 individual fields (each a separate `WriteStream` call with explicit sizes 1/2/4/16/24/32/168 bytes), converting embedded heap pointers to relative ids (e.g. `*(v7+91)` → first dword, `-1` if null; counters stored with bias `-1342`, `-1468`). This per-field pattern repeats across all `Save_Write*`/`Save_Load*`; reimplement as matching `struct` + read/write helpers honoring the version gates.

### Loader `VIBE_Save_LoadGameFile` @ 0x5a7604
`VIBE_Vfs_OpenFile("rb")` → reset world (`Building_ResetAllBuildings`,`CharAction_QueueFreeAll`,`Object_DestroySpawnedEntities`) → **`VIBE_Save_LoadHeaderAndThumbnail`** @ 0x5a7af0 (reads version `0x649D4C`, 32-byte name, 8-byte timestamp, optional fields, and a **0xE100-byte thumbnail** = 160×120×... RGB decoded via `VIBE_Result_Handler_Final` into `word_13CED76`). Validates `0x10026 <= version <= 0x10045`. Then mirror of writer: `LoadPersonIndexTable`→`LoadPersonTable`→`LoadGlobalCounters`→`LoadCityRecords`→`LoadBuildingSlotTables`→(`Amt_LoadAemter`)→`PostLoadInitScene`→`Gesetz_LoadState`→`LoadMapTiles`→`LoadGameGlobals`→`Avatar_Load`→`LoadObjectTable`→`LoadAmtTable`→`LoadHistoryAndCarts`→`LoadActionQueues`→`LoadHotkeyTable`→**`RelinkLoadedPointers`** (id→pointer fixup) → `LoadCharacters` → `Mission_LoadSlotTable` → final scene refresh.

`SaveBrowser_*` (0x569530/0x569c50/0x569d00) enumerate `.SAV` files and read just header+thumbnail for the UI. `WorldIo_*` (0x5e5ab4..) serialize per-scene object/building data (used by `.cty`/scene blocks); `ModelIo_*` (0x5e3fac..0x5e450c) read binary `.bin5`-packed 3D model/animation chunks (chunk-tag based: `ReadChunkTag`, vertex/poly/matrix/material readers).

## 4. Audio — Miles Sound System (mss32) wrapper

External: **mss32.dll**, 50 `_AIL_*` imports @ 0x60E75C..0x60E824 (samples, streams, 3D pan/rate/volume, `waveOutOpen/Close`, preferences, EOS callbacks). The game wraps these in two layers:

- **Low-level digital output / sample-bank** (`VIBE_Sound_*`, `VIBE_Audio_*` in the 0x445xxx–0x449xxx range):
  - `VIBE_Audio_StartupMilesDriver` @ 0x449840 = `AIL_startup`.
  - `VIBE_Sound_LibInit(maxMem=2097100, voices=48, channels=2, rate=44100)` @ 0x445d90 → `VIBE_Audio_OpenDigitalOutput` @ 0x449910 (`AIL_waveOutOpen`, builds a WAVEFORMAT-like struct at +6..+18, allocates a **48-byte sample slot array** ×48 = `g_sampleBank[0x62EA08]`, count `0x62EA0C`), then `VIBE_Audio_AllocateSampleHandle` (`AIL_allocate_sample_handle`) per voice. Supports up to **16 digital outputs** (`g_digOut[0x62EA1C]`).
  - Sample API: `StartVoiceSample/PlayVoiceSample/StopVoice/SetVoiceVolume/SetVoicePan/SetVoiceLoopCount` (0x447214..0x4475d4) → `AIL_start_sample`/`AIL_sample_*`. MP3 detection `VIBE_Audio_SampleIsMp3`. Sample banks `system.sbf` via `VIBE_Sound_LoadSampleBank` (0x446b2c); unload at 0x446e4c/0x447058.
  - 3D pool `VIBE_Sound3d_InitPool(64)` @ 0x424538; waveform/sine tables `VIBE_SoundWave_InitSineTables` @ 0x424d40.
- **Music / ambient streaming** (`VIBE_Audio_*Track`): `LoadTrack/StartTrack/StopTrack/FadeOutTrack/PlayAmbientTrack` (0x439ed0..0x43aa64) → `AIL_open_stream`/`AIL_start_stream`/`AIL_set_stream_*`. Mixer pump `VIBE_Audio_MixerUpdate` @ 0x43a3e4. Music thread `VIBE_Sound_InitThread(2,...,44100)`. Track name prefix = `<gamePath>msx\`.
- Volumes from INI (`msx/ambient/sfx/weather`) applied by `VIBE_Audio_ApplyVolumeSettings`. Master volume → `AIL_set_digital_master_volume`. Shutdown `VIBE_Audio_Shutdown`/`CloseAllDigitalOutputs`/`AIL_shutdown`.

**Audio handle / slot struct (48 bytes/voice)** and **digital-output struct (28 bytes**, +6 channels, +8 rate, +12 bytes/sec, +16 block align, +18 bits, +20 cursor, +24 buffer count). For reimpl: replace mss32 with OpenAL/miniaudio behind the same `VIBE_Sound_*`/`VIBE_Audio_*` facade.

## 5. Networking transport (wsock32) — feeds the Command lockstep system

External: **wsock32.dll** (`socket connect send recv select setsockopt ioctlsocket gethostbyname inet_addr htons WSAStartup/Cleanup` @ 0x60E48C..0x60E4D8). Single global TCP client socket **`g_sock[0x764CE0]`** (`-1`=disconnected), disconnect flag `0x764CF0`, RX buffer ptr `0x764CE4`/cursor `word_764CEC`, TX buffer `0x764CE8`/cursor `word_764CEE`. Byte counters `0x62E5D8`(rx)/`0x62E5E0`(tx).

### `VIBE_Net_ConnectToServer(ip, port)` @ 0x43b51c
`WSAStartup(2.0)` → `socket(AF_INET, SOCK_STREAM, IPPROTO_TCP)` → setsockopt `SO_REUSEADDR`, `TCP_NODELAY`(opt -129), `SO_RCVBUF=0x40000`, `SO_SNDBUF=0x20000` → `ioctlsocket(FIONBIO)` **non-blocking** → resolve via `inet_addr` else `gethostbyname` → `connect` → `select(writefds, 0.5s timeout)` to confirm. Stores socket. `ip==0` ⇒ local/no-net stub (returns -1, single-player).

### Packet wire format (3-byte minimum header)
`[0]`=u8 opcode/type, `[1..2]`=u16 **total length** (LE), `[4]`=u32 owner/cmdId (`-1`=none), `[8]`=u32 sequence Count. `type==0x20 && [16]==0x0E` ⇒ Sync packet.

- **`VIBE_Net_SendPacket`** @ 0x43bc54: partial-aware `send()` from `TX+cursor`, len `=*(u16*)(TX+1)-cursor`. `WSAEWOULDBLOCK(10035)`⇒retry. On complete → `VIBE_Net_AccumulatePacketStats(tx)`. Errors → teardown + `dword_764CF0=1`.
- **`VIBE_Net_ReceivePacket`** @ 0x43b8d0: stage-1 reads 3-byte header (`cursor<3`), stage-2 reads `*(u16*)(RX+1)-3` body. Tracks sequence vs `g_lastReqCount[0x7652F8]` / `cm_LastSyncCount[0x11AA470]`; logs *"nt_Recv(): Lost a Command / Received Sync / Count == cm_LastSyncCount"*. `recv()==0` ⇒ peer closed → teardown.
- Stats/format: `Net_AccumulatePacketStats` 0x43b260, `Net_FormatStatistics` 0x43b2a8, `Net_ReportWinsockError` 0x43af00, `Net_Disconnect` 0x43b868.
- **Discovery**: `Net_OpenBroadcastSocket(port 12345)` 0x43aac0, `Net_SendBroadcast` 0x43aba8, `Net_DiscoverServers` 0x43abcc, `Net_GetLocalHostAddress` 0x43b440.

### Lockstep glue (Command system — adjacent cluster, referenced heavily)
Game enqueues commands with `VIBE_Command_QueueRequest*` (returns sequence id), then `recv` loop advances state until `VIBE_Command_GetPacketStatusById(id)` is true. Network savegame transfer: host writes `.SAV`/`.SRV` to `Gamedata\network\` and ships it (`VIBE_Net_SendSaveGameToClients` 0x5abfe8 / client `VIBE_Net_LoadReceivedSaveStream` 0x5ac140 → `VIBE_Vfs_OpenMemoryStream` over the received buffer). Session sync orchestrated by `VIBE_Net_LoadAndSyncSession` @ 0x56da74 (CRC32 of save header via `VIBE_Util_Crc32`, exchanges blob #16). The host runs a separate `Server.dll` (`Init_` export). Server is single-machine in single-player (`ConnectToServer(0,0)`); multiplayer connects to a real TCP host.

## 6. Copy protection (`Drm_*`, `Disc*`, `DiscProtect_*`, `CopyProtect_*`) — STUB candidates

This is a **commercial protection wrapper (SecuROM/SafeDisc-class)**, entirely in the high `0x140xxxx`–`0x146xxxx` region (above the game's 0x4–0x6 code), entered from the packed startup at **0x1422615 → `VIBE_Drm_Main` @ 0x1414b20**. It is self-contained and separable.

- **`VIBE_Drm_Main` @ 0x1414b20** drives: `CopyProtect_VerifyDiscSignature`(0x141c720), `CopyProtect_DetectVirtualDrive`(0x141e6a0, huge — Daemon-Tools/Alcohol detection by vendor/model tables `MatchDriveModelTable`/`MatchDriveVendorTable`), and `VIBE_Drm_VerifyDisc`(0x140c3a0, 0x214f bytes).
- **`VIBE_Drm_ProtectionMain` @ 0x1411260** is a vectored-exception-driven opcode VM: hashes return addresses, uses a key table (`VIBE_Drm_LookupKeyEntry`/`InitProtection`/`DispatchKeyAction`), and decrypts overlays (`Drm_DecryptOverlay` 0x140bc10, `Drm_DescrambleBlock` 0x140ea90, `Drm_DecryptKeyTable` 0x140ec90). Installs `VIBE_Drm_VectoredExceptionHandler` (0x140f230). Embedded signature string `"UKD_548520-001.001"` @ 0x142DD28.
- **Disc layer** (`VIBE_Disc_*`, `DiscProtect_*` 0x140e4f0..0x141758x): ASPI + SPTI SCSI passthrough — TOC read, raw/ECC sector reads, set-speed, sector-timing fingerprinting (`DiscProtect_AnalyzeFrameTimings`, `MeasureSectorTimings`, `BuildSectorTable`) for the disc's physical signature; `CopyProtect_ExtractSintfDriver`/`LoadDriverExports` drop & load an ASPI driver.

**What it checks:** presence/authenticity of the original CD via SCSI sector-timing/signature analysis, plus emulator/virtual-drive detection. **Reimpl plan: stub the whole `Drm_*`/`Disc*`/`DiscProtect`/`CopyProtect` cluster** — replace `VIBE_Drm_Main`/`ProtectionMain`/`VerifyDisc` with success returns; the game logic never depends on disc data (all assets come through the VFS from disk). Risk: the overlay decryptor may decrypt parts of the real `.text` at runtime — verify whether any *game* code section is encrypted before stubbing (if so, the dumped/decrypted image must be used). The numerous `Drm_NopStub*` already present suggest most integrity hooks are inert in this build.

### Data structures to model
- **VfsHandle** (320 B) — see §2 table (name[256], stream ptr@256, rem@260, pos@264, inflate dst@268/272, flags@316).
- **VfsNode** — tree node: name, parent, child list, is-dir, zip-archive ptr + cached offset, dos-mtime. (fields via `Vfs_AddFileSorted`/`ResolvePath`/`BuildFullPath`.)
- **SaveHeader** — version u32 (0x10025–0x10045), name[32], timestamp[8], flags, gametime[14], optional id fields, 0xE100 thumbnail (160×120 RGB).
- **SocketState** (globals at 0x764CE0..0x764CF0) — sock fd, tx/rx buffer ptrs + u16 cursors, disconnect flag, byte counters.
- **AudioVoice** (48 B) and **DigitalOutput** (28 B) — §4.
- **PacketHeader** — `{u8 type; u16 len; u8 pad; u32 cmdId; u32 count; …}` (≥3 bytes on wire, but logical struct ≥17 bytes; offset 16 = sync subtype).

### External deps
kernel32 (file/FindFirst, LoadLibrary, mutex, SystemParametersInfo), user32 (window), **ddraw**/d3d (render device), **dinput** (input), **wsock32** (net), **mss32** (Miles audio), **moveahead.dll** (movie, runtime-loaded), zlib (statically linked → `Zip_*`/`Gzip_*`/`Inflate_*`). Optional ASPI driver dropped by copy-protection (ignore).

### Risks
1. DRM overlay decryptor *may* decrypt real code at runtime — confirm no game `.text` is encrypted before stubbing; if it is, work from a runtime-dumped image. (Numerous `Drm_NopStub*` suggest mostly inert.)
2. Save format is version-gated across 0x10025–0x10045; must implement every gate to round-trip all builds. Pointer↔id relinking (`Relink*`) is load-bearing and error-prone.
3. PKZIP reader is custom (`Zip_*`) not minizip-identical — verify CRC/local-header handling against real `.BINx` files; nested gz-in-zip is explicitly unsupported.
4. Lockstep determinism: `Net_ReceivePacket` sequence/sync logic must match the Command system exactly or multiplayer desyncs.
5. Many functions use `__usercall`/register args (Watcom/Borland-style) — prototypes need care at call sites.

## 8. Proposed C++ layout & implementation order

```
io/
  vfs.{h,cpp}        // VfsNode tree, VfsHandle, OpenFile/Read/Write/Seek/Close, OpenMemoryStream
  file_stream.{h,cpp}// buffered raw-file layer (VIBE_File_*)
  zip.{h,cpp}        // PKZIP .BINx reader (over zlib)
  gzip.{h,cpp}       // gzip stream + Inflate_Process
  path.{h,cpp}       // slash conversion, normalize, resolve
save/
  save_io.{h,cpp}    // WriteGameFile/LoadGameFile + versioned field serializer
  save_tables.{h,cpp}// per-table read/write (Person/Building/Object/Amt/...)
  world_io.{h,cpp}   // WorldIo_* scene serialization
  model_io.{h,cpp}   // ModelIo_* binary model/anim chunk reader
  save_browser.{h,cpp}
audio/
  sound_lib.{h,cpp}  // digital out, voice pool (Miles facade)
  audio_voice.{h,cpp}// sample play/stop/pan/vol, sample banks
  audio_music.{h,cpp}// streaming tracks/ambient
  miles_backend.{h,cpp} // mss32 OR replacement (OpenAL/miniaudio)
net/
  socket.{h,cpp}     // TCP client, framing, send/recv, discovery
  net_session.{h,cpp}// LoadAndSyncSession, save transfer
copyprotect/
  drm_stub.{h,cpp}   // success-returning stubs for Drm_*/Disc*/CopyProtect
app/
  winmain.cpp        // MainEntryAndShutdown spine
  window.{h,cpp}     // CreateMainWindow, PumpMessages
  app_init.{h,cpp}   // InitSubsystems / InitEngine / InitDisplay
  config.{h,cpp}     // gilde.INI read/write
```

**Order:** (1) `io/path` + `file_stream`; (2) `io/zip`+`gzip`+`vfs` (gates *everything*; validate against real `.BINx`); (3) `copyprotect/drm_stub` (so the binary boots); (4) `app/config`+`window`+`app_init`+`winmain` spine (window + DInput + render-device hookpoints can be thin shims first); (5) `save/*` (round-trip a `.cty` then a `.SAV`); (6) `audio/*` behind the Miles facade; (7) `net/*` last (single-player local stub works without it). The frame loop / Command lockstep belongs to a separate cluster — expose `RunFrameLoop`/`PumpMessages` as integration points.
