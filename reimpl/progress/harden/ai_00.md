# Harden chunk ai_00 — AI / MeisterAi modules (22 files)

1:1 hardening sweep of every `gilde.exe 0xADDR` provenance'd function in the 22
`src/ai/*.cpp` files of chunk ai_00. Each function was decompiled + disassembled via
live IDA MCP and diffed line-for-line against the binary (DISASM authoritative over
Hex-Rays); constants/tables confirmed byte-exact via `get_bytes`/`get_global_value`.
Divergences and wrong goldens fixed to the binary with addr+evidence; correct
reconstructions marked VERIFIED-1:1 with no churn.

Work fanned out to 8 parallel sub-agents (one per file cluster). Per-cluster detail in
the sibling files listed below.

## Notable fixes (binary-confirmed)

- **CheckObjectState** (0x47bcd8): Hex-Rays collapsed two distinct `RandomModulo`
  calls (`mov eax,3` then `mov eax,4`) into one phantom shared `n`. Rewrote to the two
  hardcoded moduli; golden corrected.
- **EvaluateHand** (0x466980, cardgame): draw-path RNG count+order was materially
  wrong (wrong redeal count, dropped band-dependent burn draw, phantom extra draw).
  Rewritten 1:1 — the highest-risk fix in the chunk.
- **DecideMove** (0x466ec4): card-game knock gate used OWN hand size; disasm shows
  OPPONENT's. Fixed.
- **CanPlayCard/PlayCard transition table** (0x4668d4): re-decoded from raw bytes;
  prior table was bogus. Result == played action.
- **ComputeChoiceWeights** (0x4684ec): per-slot pick is table-resolved
  (`dword_4664B8` rows) with a base byte, not raw `RandomModulo(3)`. Added table +
  base; golden corrected.
- **EvaluateSessionDecision moduli** (0x4a481c): types 1/2/6 hardcode 2/7/2 in the
  binary (RandomBoolCheck@0x46797c, RandomValue@0x467994, case6@0x4a48e2). Fixed all
  three; removed the fabricated `SessionInputs::randModulus`; corrected both
  integration + e2e goldens (e.g. `13 % 7 = 6`). Verified 87/87 meisterai3 checks pass.
- **ClassifyWealthTier** (0x467d60): used `std::floor`; binary uses
  `NormalizeAngle`-style trunc (= `trunc(x)` for x>=0, `trunc(x)-1` for x<0). Fixed.
- **RandomBoolCheck/RandomValue** (0x46797c/0x467994): moduli hardcoded 2/7, not
  pass-through args. Signatures fixed.
- **CheckSameFaction** (0x47b9c8): `% 4` is signed `idiv`, was unsigned. Fixed.
- **PlanProductionRatio** (0x4596e4): tier-1/tier-3 production-scale constants were
  swapped vs `flt_6198E8`/`flt_6198F0` (byte-confirmed). Source + golden fixed.
- **BuildProbability** (0x4c7774): `gameTick/4` truncates toward zero (MSVC
  sar/shl/sbb idiom), not `gameTick>>2` (rounds to -inf for negatives). Fixed.
- **CheckWorkstationCapacity** (0x45ba84): three field-mapping bugs (need-vs-stock,
  flags50-vs-freeCap, stock-vs-reserved) + a cheap-analogue supply helper replaced
  with the faithful 0x45bc62 math. Source + goldens fixed.
- **ReserveWorkstationItems** (0x45bd68): wrong clamp field, missing `bits|=0x8`,
  cheap-analogue raw-material branch replaced with the faithful seller iteration.
- **FlagIdleStaff** (0x45df7c): already-supervised returned -1 (binary returns 0);
  both passes missing the owner gate `ownerBuildId==buildId`. Fixed.

Float→int sites across the chunk were checked against the disasm: `VIBE_Coord_ConvertX`
@0x5c6b08 truncates toward zero (RC=11 + frndint) == `(int)` cast, confirmed at the
trade pricing, weight, and tier sites. The 483-byte desire goods table (dword_6496A9),
the finder radius table (0x61AC30), the card transition table, the choice table, and
all RuleEval/favorability .rdata float constants were re-read byte-for-byte and confirmed.
